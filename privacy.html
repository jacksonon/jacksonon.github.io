Right AI Privacy Policy

Effective date: August 22, 2026 Applies to: Right AI (Chrome extension)

01Overview

Right AI ("the extension") is a browser sidebar assistant that provides multi-model AI chat, selection translation, image OCR, quick input into AI websites, a stock ticker, and an Omni browser agent that can read and operate web pages on your behalf.

This policy explains what data the extension handles, where it is stored, and which third parties may receive it when you use specific features. It applies only to the extension itself. When you use third-party AI services (through your own accounts and API keys), their own privacy policies govern your data.

In short: Right AI has no developer-operated servers, no user accounts, no analytics, and no advertising SDKs inside the extension. Your settings and history stay in your browser; prompts are sent directly by your browser to the AI provider you choose.

02Data we do not collect

  • We do not operate any backend server that receives your data.
  • We do not require or create user accounts.
  • We do not collect analytics, telemetry, advertising identifiers, or browsing histories.
  • We do not sell or rent personal data to anyone.
  • We do not use your data for any purpose unrelated to the feature you invoked.

03Data stored locally on your device

The following data is stored only on your computer using browser-provided storage:

  • Settings & preferences — language, shortcuts, feature toggles, toolbar layout, custom navigation links.
  • Your AI API key — if you configure your own model API key (for example, a Zhipu BigModel key), it is stored via chrome.storage.sync, which syncs it through your own Chrome profile across devices you control.
  • Caches — chat history cache, translation/OCR result cache, and quick-input state, stored via chrome.storage.local / localStorage.

You can export this configuration as a local file from the settings panel and re-import it at any time. Uninstalling the extension removes all of the above.

04Third parties that receive data when you use features

The extension itself sends nothing anywhere until you invoke a feature. At that moment:

  1. AI model providers (e.g., Zhipu BigModel). Chat, translation, and OCR requests are made directly from your browser to the endpoint of the provider whose API key you configured. The request includes your prompt and, when you explicitly enable it, the page context or image you asked about. That provider processes the request under its own privacy policy.
  2. AI websites you open in the sidebar (ChatGPT, Claude, Gemini, DeepSeek, Kimi, Qwen, etc.). These load exactly as they would in a normal tab, under their own terms. Quick Input only types the text you supply into the focused conversation.
  3. Sina Finance quote service. If you enable the stock ticker, the extension requests public quotes for the stock codes you follow (hq.sinajs.cn). Only the ticker codes are sent; no personal data is included.
  4. Google favicon service. For custom links you add, the extension requests a site icon from www.google.com/s2/favicons. Only the site domain is sent.

05Access to page content

Right AI can technically run on all pages, but it reads page content only when a feature you triggered needs it, for example:

  • translating text you select;
  • performing OCR on an image you pick;
  • attaching "this page's context" to a chat prompt when you ask for it;
  • extracting stack traces on a crash-analysis page or build logs on a Jenkins console page you opened;
  • letting the Omni agent read and act on a page while an agent task is running.

Page content collected this way is used immediately for the requested action. Except as described in Section 04, it is not transmitted to us (we have no servers) and is not retained beyond local caches you can clear.

06The Omni browser agent

Omni is an optional agent that can operate the current tab on your behalf: reading page structure, clicking, filling forms, and switching tabs. While an agent task runs, it uses the Chrome DevTools Protocol on the tab you launched it from.

  • Agent tasks start only when you start them, and only in tabs you target.
  • Risky actions (navigation, form submission, running page scripts) require your explicit confirmation in a side-panel card before they execute.
  • Any files or results are written only to locations you authorize.
  • You can stop an agent task at any time.

07Permissions and how they are used

Permission Why it is needed
sidePanel Core UI: opens Right AI as a Chrome side panel.
tabs / activeTab Detect the active tab so features apply to what you are viewing; list tabs for agent tasks.
host_permissions (<all_urls>) / scripting Inject the translation / OCR / Quick Input overlay and read page context on demand (Section 05).
storage Store settings, caches, and your API key locally (Section 03).
declarativeNetRequest (+Feedback) Adjust request headers where required (e.g., Referer for stock quotes) and allow AI sites to render inside split view.
debugger Powers the Omni agent's page automation while a task runs (Section 06).
tabGroups Organize tabs created during agent tasks.
downloads Save exports and agent results to locations you choose.
notifications Notify you when long-running tasks finish.
alarms Schedule periodic refreshes (e.g., stock ticker interval).
offscreen Run hidden processing steps that require an offscreen document (e.g., preparing images before OCR).
commands Keyboard shortcuts you press to open features.

08Data retention and deletion

  • All locally stored data (Section 03) persists until you remove it.
  • You can clear caches and reset settings inside the extension, or export/import them as files.
  • Uninstalling Right AI deletes all extension storage automatically.
  • Data held by third-party providers (your chats with an AI service) is governed by those providers' retention policies.

09Security

Because there is no intermediary server, your prompts travel directly over HTTPS from your browser to the provider you selected. Your API key is stored in browser-managed extension storage and is never included in pages or shared with other sites. We recommend using a dedicated API key with spending limits you are comfortable with.

10Children's privacy

Right AI is a productivity tool not directed at children. We do not knowingly collect personal information from children under 13 (or the minimum age required by your local law).

11Changes to this policy

We may update this policy when the extension's behavior changes. The effective date above will always reflect the latest version. Material changes will be highlighted in the extension's release notes before they take effect.

Chrome 扩展 · 隐私政策

Right AI 隐私政策

生效日期：2026 年 8 月 22 日 适用范围：Right AI（Chrome 扩展）

01概述

Right AI（下称"本扩展"）是一款浏览器侧边栏助手，提供多模型 AI 对话、划词翻译、图片 OCR、 向 AI 网站快捷输入、行情跑马灯，以及可代你阅读和操作网页的 Omni 浏览器代理。

本政策说明本扩展处理哪些数据、数据存放在哪里，以及在您使用特定功能时哪些第三方可能收到数据。 本政策仅适用于本扩展本身。当您通过自己的账号与 API Key 使用第三方 AI 服务时， 您的数据受那些服务商自身隐私政策的约束。

一句话总结：本扩展没有开发者服务器、没有账号体系、没有统计埋点、 没有广告 SDK。您的设置与历史保存在本地浏览器中；提问内容由您的浏览器直接发送给您选择的服务商。

02我们不收集的数据

  • 我们不运营任何接收您数据的后端服务器。
  • 我们不要求也不创建用户账号。
  • 我们不收集统计数据、遥测信息、广告标识符或浏览历史。
  • 我们不向任何人出售或出租个人数据。
  • 我们不将您的数据用于您所触发功能之外的任何目的。

03仅保存在您设备上的数据

以下数据仅通过浏览器提供的存储能力保存在您的电脑上：

  • 设置与偏好 —— 语言、快捷键、功能开关、工具栏布局、自定义导航链接。
  • 您的 AI API Key —— 若您配置了自己的模型密钥（例如智谱 BigModel Key）， 它会保存到 chrome.storage.sync，仅通过您自己的 Chrome 账号在您控制的设备间同步。
  • 缓存 —— 对话历史缓存、翻译/OCR 结果缓存、快捷输入状态， 保存在 chrome.storage.local 与 localStorage 中。

您可以在设置面板中将配置导出为本地文件，也可随时重新导入。卸载本扩展将删除上述全部数据。

04使用功能时会接收数据的第三方

在您触发某个功能之前，本扩展不会向任何地方发送数据。触发后：

  1. AI 模型服务商（如智谱 BigModel）。对话、翻译、OCR 请求由您的浏览器直接发往 您所配置密钥对应的服务商接口。请求包含您的提问内容；当您明确开启相关选项时，还会包含您要求附带的 页面上下文或图片。该请求由服务商按其隐私政策处理。
  2. 您在侧边栏中打开的 AI 网站（ChatGPT、Claude、Gemini、DeepSeek、Kimi、Qwen 等）。 它们的加载方式与普通标签页完全一致，并适用其各自的条款。快捷输入只会把您输入的文本注入当前聚焦的会话框。
  3. 新浪财经行情服务。若启用股票跑马灯，扩展会为您关注的代码请求公开行情 （hq.sinajs.cn）。请求只包含股票代码，不含任何个人数据。
  4. Google 图标服务。为您添加的自定义链接获取站点图标时，会请求 www.google.com/s2/favicons。仅发送站点域名。

05对页面内容的访问

Right AI 技术上可在所有页面运行，但只有在您触发的功能需要时才会读取页面内容，例如：

  • 翻译您选中的文本；
  • 对您选择的图片进行 OCR 识别；
  • 当您要求时，把"当前页面上下文"附加到对话提示中；
  • 在崩溃分析页提取堆栈、在您打开的 Jenkins 控制台页提取构建日志；
  • 代理任务运行期间，由 Omni 读取并操作目标页面。

以上方式收集的页面内容仅立即用于您请求的操作。除第 04 条所述情形外，它不会被传输给我们 （我们没有服务器），也不会保留在您可以清除的本地缓存之外。

06Omni 浏览器代理

Omni 是可选的自动化代理，可以代您操作当前标签页：读取页面结构、点击、填写表单、切换标签。 任务运行期间，它会通过 Chrome DevTools Protocol 作用于您启动它的那个标签页。

  • 任务仅在您主动启动时开始，且仅作用于您指定的标签页。
  • 高风险操作（跳转、提交表单、运行页面脚本）执行前会在侧边栏弹出确认卡片，需您明确确认。
  • 产生的文件或结果只会写入您授权的位置。
  • 您可以随时终止代理任务。

08数据保留与删除

  • 第 03 条所述本地数据会一直保留，直到您主动删除。
  • 您可以在扩展内清除缓存、重置设置，或将配置导出/导入为文件。
  • 卸载 Right AI 会自动删除全部扩展存储。
  • 第三方服务商保留的数据（例如您与某 AI 服务的聊天记录）受相应服务商政策约束。

09数据安全

由于不存在中间服务器，您的提问内容通过 HTTPS 从浏览器直达您选择的服务商。API Key 保存在 浏览器管理的扩展存储中，不会出现在网页里，也不会共享给其他站点。建议您使用设置了消费限额的专用密钥。

10未成年人隐私

Right AI 是一款面向效率的工具，不面向儿童推广。我们不会有意收集 13 岁以下 （或您所在地法律规定的最低年龄以下）儿童的个人信息。

11政策更新

当扩展行为发生变化时，我们会更新本政策。上方生效日期始终对应最新版本。 重大变更会在生效前通过扩展的版本更新说明予以提示。
