Omni 从裸 SDK 循环到生产级自主执行回路

大语言模型是 Agent 的大脑，但真实工程需要坚不可摧的执行回路与安全护栏。

Omni 摒弃黑盒框架抽象，回归流式调用、并行工具执行与自我纠错最本真的形态，让 Agent 稳定落地复杂编程场景。

裸 SDK 主循环与自纠错

BARE SDK LOOP & SELF-CORRECTION

流式调用 LLM → 并行执行工具调用 → 执行结果回传自纠错闭环。工具执行失败信息原样回传模型，由模型自行理解并自愈代码缺陷，杜绝框架吞错。

权限分级与 OS 级进程沙箱

PERMISSIONS & OS-LEVEL SANDBOX

内置 full / safe / ask / read 四级权限，危险命令正则拦截与审批卡片；底层集成 macOS sandbox-exec 与 Linux bwrap 进程隔离，网络白名单过滤代理出网（TLS 不解密）。

级联记忆与动态技能生态

CASCADE MEMORY & AGENT SKILLS

项目级与全局级 AGENTS.md 级联加载，首轮自动注入；自动扫描 .opencode/skills 与 .claude/skills 下的 SKILL.md 并按需渐进披露；支持会话 JSONL 持久化与长对话摘要压缩。

Web 工作台与多会话并发（Electron 跨平台）

分层内核、8 执行工具与安全沙箱

入口层统一调度单 Agent 主循环与自我纠错闭环；6 个基础工具 + 动态注入 delegate（子代理 git worktree 临时分支隔离）与 mcp_* 外部工具；macOS sandbox-exec 与 Linux bwrap 进程沙箱，全生命周期 Hooks 拦截自愈。

开始使用

多元化安装与运行方案

npx Web 免安装体验

无需全局安装，一行命令即刻拉起本地服务并唤起浏览器 Web 工作台，体验完整多会话 Agent 交互。

$ npx @right-ai/omni web

npm / bun 全局安装

支持 npm 或 bun 全局安装 @right-ai/omni，随时随地在终端调度 Agent。

$ npm install -g @right-ai/omni

curl 一键安装（原生二进制）

零依赖原生二进制文件，自动识别平台架构，自带完整全屏 OpenTUI 沉浸交互体验。

$ curl -fsSL https://raw.githubusercontent.com/jacksonon/omni/main/scripts/install.sh | sh

Electron 桌面端（免环境依赖）

macOS (Apple Silicon / Intel)、Windows (.exe)、Linux (.AppImage) 独立安装包，内置运行环境开箱即用。

$ open https://github.com/jacksonon/omni/releases/latest 前往 Releases
