Omni — 浏览器代理：给它一个目标，替你「动手」

  • 读写文件：read_file / write_file / diff_file。可授权整个目录，也可只勾选若干文件，每次访问都会写入审计日志。
  • 驱动页面：截图、运行受限页面 JavaScript（无法访问 Chrome 扩展 API 与本地文件）、打开新标签、切换标签、罗列标签。
  • 复合任务：perform_task。一句话目标，端到端执行，流式进度实时显示在侧边栏。
  • 一切本地优先：API Key、设置与审计日志只留在你的设备上；所有有副作用的动作都会先在侧边栏列出要做什么，等你确认后再执行。

快速开始

3 分钟内完成安装并启动第一条命令

快速安装

  1. 从 Chrome Web Store 安装 Right AI ，或下载 离线包 进行手动安装。
  2. 打开扩展页面，固定 Right AI 到工具栏。
  3. 进入任意网页，按 Ctrl + R 立即唤起 Quick Input。

手动安装路径：chrome://extensions → Developer mode → Load unpacked

版本更新节奏

  • 月更：跟进最新 AI 资讯，持续提供符合当前场景的 AI 服务。

建议开启自动更新，让 Right AI 持续贴合最新模型能力与使用场景。

AI 快速输入对话页（新）

  • 唤起后可在网页右下角直接进入模型对话界面。
  • 设置新增「快捷弹窗显示模型对话页」与「唤起时切回 Chrome 前台」。
  • 可开启「再次按快捷键关闭快捷对话窗口」实现快速开关。

建议在扩展设置中按你的使用习惯组合上述选项。

免费模型获取

OpenCode Zen 免费 API Key 获取指南

注册免费的 OpenCode 账号并创建 API Key，即可让 Omni 使用 Zen 的免费模型。

  1. 前往 OpenCode 注册 / 登录并创建 API Key。
  2. 进入「API 密钥」→「创建 API 密钥」，然后复制生成的密钥。
  3. 回到 Omni 设置页，在 API Key 中粘贴密钥，并将 Base URL 填为： https://opencode.ai/zen/v1
  4. 测试连接，并在模型列表中选择带有 free 字样的模型，即可开始使用 Omni。

提示：免费模型的可用性、限额和服务条款以 OpenCode Zen 当前页面为准。

常见问题

你可能关心的问题

Right AI 支持哪些浏览器？

推荐最新版 Chrome。基于 Chromium 的 Edge 等浏览器通常也可正常运行。

我必须登录账号才能用吗？

安装后即可使用核心能力。部分模型服务可能需要你在扩展内配置自己的 API 信息。

如何快速调起输入面板？

默认推荐快捷键是 Ctrl + R，用于唤起右侧面板。你也可以在 Right AI 设置中自定义快捷键。

离线包应该怎么安装？

下载 files/dist.zip，解压后在 chrome://extensions 开启开发者模式并选择"加载已解压的扩展程序"。

快捷键怎么设置更顺手？

推荐按下面的方式配置：

快捷键 对应功能
Control + R 唤起右侧面板。
Control + Q 快速发消息或唤起 AI 浮层窗口。
Control + L 网页亮度适配。

这些设置需要在 Right AI 面板内点击"设置"，并在对应条目里完成配置。
