Right AI Omni Agent Harness

极简透明高效

Right AI Omni 是一个开源（BSD-3-Clause）的终端型 Agent 工程 / Agent Harness，源代码公开可查。

模型与提供商配置、工具执行、权限审批、上下文管理和子代理协作集中在同一内核。支持 TUI、Web、mini CLI 与 Electron，也能从手机浏览器连接电脑上的 Agent。

执行回路 · 可追踪，可干预

从一个任务，到可验证的结果

基于原生 OpenAI SDK 构建。模型决定下一步，Omni 负责上下文、执行边界和结果回传，让每一步都有迹可循。

  1. 01

    组装上下文

    读取项目指引、相关文件与会话历史；长任务通过摘要与压缩管理上下文。

  2. 02

    流式调用模型

    通过模型提供商配置连接 Chat Completions 或 Responses，输出回答或工具调用。

  3. 03

    检查执行边界

    每次工具调用经过权限策略、审批与审计；按配置启用命令沙箱和生命周期 Hooks。

  4. 04

    执行并回传结果

    并行执行本轮工具，将结果按顺序返回模型；失败与拒绝也进入下一轮判断。

工具结果 → 更新上下文 → 继续执行，直到模型给出回答或达到步数上限。

CONTROL

权限与沙箱，分别配置

full / safe / ask / read 四级权限，默认 safe。OS 沙箱默认关闭；启用后默认 fail-closed，无法提供所需隔离时拒绝执行。Windows 原生沙箱尚未实现。

CONTEXT

上下文随任务延续

全局与项目 AGENTS.md 级联加载，SKILL.md 按需读取；JSONL 会话持久化、摘要压缩与检查点支持长任务和后续恢复。

COORDINATION

从单循环到任务协作

支持前后台子代理、共享任务看板与消息通信；工作流按依赖分批执行，子代理可选择 git worktree 隔离。通过 MCP、插件与 Hooks 扩展能力。

一个内核 · 多种入口

同一个 Agent 内核，四种工作方式

从终端到桌面，再到手机浏览器。各入口复用 Agent 循环与工具能力，按使用场景提供不同的交互方式。

全屏终端，专注键盘工作流

OpenTUI 提供流式思考、工具卡片、Markdown 与 Diff；用 @ 浏览文件，用斜杠命令切换模型、管理任务与会话。

omni

浏览器工作台，也能从手机接入

按工作区管理多个会话，查看工具执行与 Diff，响应审批和提问。移动端抽屉导航配合账号登录、扫码配对与隧道，连接你电脑上的 Agent。

omni web

滚屏终端，保留熟悉的命令行节奏

行式呈现流式回答、工具输出与每轮 token、耗时统计；交互选择器使用临时屏幕。自动化与管道场景可使用 omni exec 的结构化输出。

omni mini

独立桌面窗口，内置运行环境

提供 macOS、Windows、Linux 安装包，在独立窗口中使用 Web 工作台与本地后端，无需单独安装 Node.js。下图展示共用的 Web 界面。

REMOTE ACCESS · v0.9.1

电脑上执行，手机上继续

通过浏览器发送任务、查看执行进展、处理审批与提问。代码、命令和 Agent 后端仍在运行 Omni 的电脑上执行；电脑与服务需要保持在线。

手机 / 另一台电脑 ↔ 局域网 / HTTPS 隧道 + 登录认证 ↔ 你的电脑 · Omni Web + Agent

首次接入：先在电脑上设置账号密码

密码以 scrypt 哈希保存。扫码使用 5 分钟有效、单次兑换的配对码；后续也可使用账号密码登录。

omni web auth set
01 / LAN

同一网络，扫码配对

电脑启动后显示局域网链接与终端二维码。手机连接同一局域网，扫码进入 Web 工作台。

omni pair

也可运行 omni web --host 0.0.0.0，使用局域网地址和账号密码登录。

02 / HTTPS

离开局域网，通过隧道接入

安装 cloudflared 后，生成临时公网 HTTPS 地址。使用账号密码登录，手机浏览器可在 HTTPS 下添加到主屏幕。

omni web --tunnel

临时地址用于快速连接；固定域名与长期访问可配置 Cloudflare 命名隧道。

03 / macOS

常驻服务，管理启停与自启

已配置命名隧道及其本地配置文件后，用 LaunchAgent 管理 Web 与隧道进程。此服务管理命令目前仅支持 macOS。

omni service install --tunnel omni

将 omni 替换为你的隧道名。start / stop / restart 控制运行状态；enable / disable 单独控制登录自启；status 查看状态。

远程消息自动适配：优先使用 SSE；遇到隧道缓冲等情况，自动回退长轮询，继续接收任务事件。

开始使用

多元化安装与运行方案

npx Web 免安装体验

无需全局安装，一行命令即刻拉起本地服务并唤起浏览器 Web 工作台，体验完整多会话 Agent 交互。

$ npx @right-ai/omni web

npm / bun 全局安装

支持 npm 或 bun 全局安装 @right-ai/omni，随时随地在终端调度 Agent。

$ npm install -g @right-ai/omni

curl 一键安装（原生二进制）

零依赖原生二进制文件，自动识别平台架构，自带完整全屏 OpenTUI 沉浸交互体验。

$ curl -fsSL https://raw.githubusercontent.com/jacksonon/omni/main/scripts/install.sh | sh

Electron 桌面端（免环境依赖）

macOS (Apple Silicon / Intel)、Windows (.exe)、Linux (.AppImage) 独立安装包，内置运行环境开箱即用。

$ open https://github.com/jacksonon/omni/releases/latest 前往 Releases
